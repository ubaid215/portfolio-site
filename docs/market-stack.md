# Portfolio technology positioning

Reviewed on 2026-10-09. The section shows tools the owner has confirmed or that appear in the existing application and project data. It is a capabilities presentation, rather than a universal ranking of hiring demand.

## Market signals

- [Stack Overflow Developer Survey 2026: Technology](https://survey.stackoverflow.co/2026/technology) reports sustained use of JavaScript, SQL, Python, and TypeScript, continued PostgreSQL adoption, and broad use of Anthropic and OpenAI models.
- [GitHub Octoverse: TypeScript, Python, and the AI feedback loop](https://github.blog/news-insights/octoverse/typescript-python-and-the-ai-feedback-loop-changing-software-development/) reports TypeScript becoming the most-used language on GitHub in 2025.
- [LinkedIn's 2026 US software engineer talent landscape](https://economicgraph.linkedin.com/content/dam/me/economicgraph/en-us/PDF/us-software-engineer-talent-landscape-2026.pdf) describes demand for core programming, cloud, Python, SQL, React, and AI-related skills. This evidence is specific to the US market; the full PDF was not accessible through the research tool, so the portfolio uses no rankings or numerical claims from it.

These sources measure different things: developer adoption, repository activity, and hiring patterns. They support the direction of the section without establishing one global “most demanded” stack.

## What changed

The section groups tools into web experience, SaaS engineering, AI automation, and data and delivery. OpenAI API, Claude API, LangChain, n8n, and Docker were explicitly confirmed by the owner. React, Next.js, TypeScript, PostgreSQL, and the other existing tools remain grounded in project or application evidence.

Python is relevant to the market research but is not presented as a current skill because the owner has not confirmed using it. No skill scores, experience durations, or proficiency ratings are invented.
